### Opera Build Command Logs

This directory contains raw command logs for building and simulating the model in **Opera 3D**.

`логи_моделер.txt` and `логи_пост_процессор.txt` — raw logs for model construction and field calculation respectively, including inline comments and the `Opera-3d > ` line prefix. Comments and the prefix are removed by [`scripts.py`](https://github.com/Askash1234567890/Diploma/blob/main/scripts/scripts.py) in the [`scripts/`](https://github.com/Askash1234567890/Diploma/blob/main/scripts) directory.

`check.comi` and `check_post.comi` — cleaned files ready for import into the Opera modeler and post-processor respectively.

`полное создание катушки и полюса.txt` — auxiliary file used to construct `логи_моделер.txt`.
