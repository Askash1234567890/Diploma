### Trained Models and Derived Results

## models_2.zip

A zip archive of the trained **SVR** models for h6/h2, h10/h2, and h14/h2. Training used 10-fold stratified cross-validation, so there are 10 model instances per harmonic (30 files total).

## svr_h_data.zip

Contains three CSV files with **smoothed** 500×500 prediction surfaces for each harmonic ratio, generated by querying the trained SVR models over a fine grid. The raw simulation grid is 32×32; the SVR ensemble interpolates it to 500×500 for visualization and precise optimum localization.

## fields_data.zip

Text files with magnetic field data used to produce the presentation plots:
- Total field magnitude `|B|` along the reference circle for a non-optimal shape
- Tangential component `B_θ` for a non-optimal shape
- Total field magnitude `|B|` for the optimized shape (harmonics suppressed)
